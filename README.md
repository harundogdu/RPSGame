# Rock Paper Scissors Game

A browser-based Rock Paper Scissors game built with vanilla HTML, CSS, and JavaScript. Pick your move, click Fight, and play against the computer until someone reaches 5 wins.

## Tech Stack

- HTML5 / CSS3
- Vanilla JavaScript (DOM manipulation, no framework)
- [SweetAlert](https://sweetalert.js.org/) for win/loss dialogs
- [darkmode-js](https://github.com/sandoche/Darkmode.js) for the dark mode toggle widget

## How to Play

1. Open `index.html` in a browser.
2. Click rock, paper, or scissors to set your choice.
3. Click **Fight** to play a round against the computer.
4. The score updates after each round, and the first side to reach 5 wins ends the game.

## Getting Started

No build step or dependencies to install. Clone the repo and open `index.html` directly, or serve the folder with any static file server:

```bash
git clone https://github.com/harundogdu/RPSGame.git
cd RPSGame
open index.html
```
